# Presentation Deliverables

This directory is dedicated to storing presentation slides, materials, and related files for different development sprints in the **Rookie Data DN 2026** project.

## Purpose

The presentation files are organized by sprint and individual rookie/team deliverables to ensure:
- Clear structure and tracking of weekly/sprint progress.
- Easy access to HTML-based presentations and slides.
- Proper archival of the final sprint demonstrations.

## Directory Structure

- `sprint03/`: Presentation decks for Sprint 03.
  - `rookie12/`: Presentation folder for Rookie 12.
  - `rookie14/`: Presentation folder for Rookie 14.
  - `rookie15/`: Presentation folder for Rookie 15.
  - `rookie16/`: Presentation folder for Rookie 16.
  - `rookie17/`: Presentation folder for Rookie 17.
  - `rookie20/`: Presentation folder for Rookie 20.
  - `sprint03-final/`: Final unified presentation slide deck for Sprint 03.
- `sprint04/`: Presentation decks for Sprint 04.
