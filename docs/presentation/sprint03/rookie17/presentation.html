Load Strategy

FULL and INCREMENTAL Load

FULL Load Used for initial loading and small reference sources. The pipeline loads the required data into Bronze from the source.
INCREMENTAL Load Used after the initial load. The pipeline only picks up new or changed records based on watermark or file tracking.
Execution Context

Shared Context Variables

  • ✓run_mode:  controls NEW or RECOVERY execution.
  • ✓batch_id:  logical batch shared across layers.
  • ✓session_id:  unique execution session for one pipeline run.
  • ✓previous_session_id:  failed session used for recovery lineage.
Run Modes

NEW vs RECOVERY

NEW Mode Generate a new batch_id and create a new session_id for a normal pipeline run.
RECOVERY Mode Reuse the existing batch_id, create a new session_id, and keep previous_session_id for failed-session lineage.
